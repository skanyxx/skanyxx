| D004 | 2026-09-16 | **One UI, three roles** (owner, builder, employee). Any of them can be the first user. | Same product; home/permissions change with role. Not three apps. |

| D008 | 2026-09-16 | Do **not** treat kagent’s built-in agent memory as the company memory bank. | kagent memory is per-agent, TTL (default 15 days), **no cross-agent sharing** ([agent memory](https://kagent.dev/docs/kagent/concepts/agent-memory/)). kagent itself says a company store should come in as **MCP**. |
| D009 | 2026-09-16 | People can **search and open** memory items in Skanyxx. This is a knowledge library, **not a file explorer**. Daily use is still mostly through agents. | Later someone must read *what* we did and *why* without guessing. A folder tree of files is the wrong metaphor. |
