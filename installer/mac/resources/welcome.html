Welcome to Skanyxx SRE Platform

Skanyxx is a modular SRE platform for Kubernetes management, agent orchestration, and monitoring. It runs as a local web application on http://localhost:5282.

This installer will place Skanyxx in /usr/local/share/skanyxx and add a command-line launcher at /usr/local/bin/skanyxx.

After installation, open /usr/local/share/skanyxx/appsettings.json and add your Anthropic API key before starting the app.
