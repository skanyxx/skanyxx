Installation Complete!

Next steps

1. Add your Anthropic API key:
/usr/local/share/skanyxx/appsettings.json
Set "ApiKey": "sk-ant-..."
2. Start the app:
skanyxx
3. Open in your browser:
http://localhost:5282
4. Create the owner account: the setup page asks for the bootstrap token that was generated for you. It is "Identity": { "BootstrapToken": … } in the same appsettings.json. Keep it: it is also the owner's way back in when the account is locked. The file is readable by administrator accounts only; edit it with sudo.
Upgrading from a version without accounts? Your existing appsettings.json is left as it was and has no token: set Identity:BootstrapToken there yourself (a random string of at least 32 characters, e.g. openssl rand -hex 24).

To uninstall

sudo rm -rf /usr/local/share/skanyxx
sudo rm -f /usr/local/bin/skanyxx
sudo rm -f /Library/LaunchAgents/com.skanyxx.app.plist
