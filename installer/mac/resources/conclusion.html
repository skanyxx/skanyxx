Next steps

This is the desktop launcher: it opens your company's Skanyxx. The Skanyxx server itself is installed with the Helm chart, not on this Mac.

1. Set your company's Skanyxx address (ask its owner) in /usr/local/share/skanyxx/appsettings.json (edit it with sudo):
"Skanyxx": { "Mode": "Remote", "RemoteUrl": "https://skanyxx.example.com", … }
2. Start the app:
skanyxx
3. Open http://localhost:5282: it takes you to your company's Skanyxx, where you sign in.

Upgrading?

An existing appsettings.json is left as it was. Without "Mode" it keeps running a full Skanyxx with its own data on this Mac: a dev console, not your company's workspace. Set "Mode": "Remote" and "RemoteUrl" to open the company's Skanyxx instead. In that full mode, /Setup asks for Identity:BootstrapToken from the same file (a random string of at least 32 characters, e.g. openssl rand -hex 24), and the model and its key are set on the owner's /Model page.

To uninstall

sudo rm -rf /usr/local/share/skanyxx
sudo rm -f /usr/local/bin/skanyxx
sudo rm -f /Library/LaunchAgents/com.skanyxx.app.plist
