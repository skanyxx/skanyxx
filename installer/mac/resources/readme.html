Before You Install

Requirements

  • macOS 15.0 (Sequoia) or later
  • Your company's Skanyxx address (ask its owner)

What gets installed

  • /usr/local/share/skanyxx/ — application files
  • /usr/local/bin/skanyxx — command-line launcher
  • /Library/LaunchAgents/com.skanyxx.app.plist — launchd agent (not auto-started)

After install

Start the app: skanyxx opens your company's Skanyxx in your browser.

skanyxx
# or
cd /usr/local/share/skanyxx && ./Skanyxx.Host open

Want a fixed local address for bookmarks? launchctl start com.skanyxx.app (or cd /usr/local/share/skanyxx && ./Skanyxx.Host --urls http://127.0.0.1:5282), then open http://127.0.0.1:5282. That port is shared by every account on this Mac.

macOS Gatekeeper

A signed and notarized release opens directly. An unsigned build is blocked when you open it: allow it once in System Settings → Privacy & Security → "Open Anyway". Nothing needs to be run on the installed files.
