Before You Install

Requirements

  • macOS 12.0 (Monterey) or later
  • An Anthropic API key (for AI features)
  • KAgent server (for Kubernetes features — optional)

What gets installed

  • /usr/local/share/skanyxx/ — application files
  • /usr/local/bin/skanyxx — command-line launcher
  • /Library/LaunchAgents/com.skanyxx.app.plist — launchd agent (not auto-started)

After install

Start the app from Terminal:

skanyxx
# or
/usr/local/share/skanyxx/Skanyxx.Host --urls http://localhost:5282

Then open http://localhost:5282 in your browser.

macOS Gatekeeper

If macOS says the app is "damaged" or "from an unidentified developer", run this command once in Terminal: 

xattr -cr /usr/local/share/skanyxx/Skanyxx.Host
